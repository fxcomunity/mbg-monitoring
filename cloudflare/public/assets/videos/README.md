# Kategori Aset Video — Radar MBG Nasional (Badan Gizi Nasional)

Folder ini dialokasikan khusus untuk penyimpanan dan pengelolaan media video operasional program Makan Bergizi Gratis (MBG):

## 1. Jenis Video yang Didukung:
- **Dokumentasi Dapur SPPG (`sppg-dapur-*.mp4`)**:
  Rekaman verifikasi higienitas, sanitasi, dan proses memasak bahan pangan bergizi oleh tim katering SPPG.
- **Monitoring Distribusi (`distribusi-*.mp4`)**:
  Dokumentasi keberangkatan armada boks insulasi dan serah-terima makanan ke sekolah target.
- **Video Edukasi Siswa & Wali (`edukasi-gizi-*.mp4`)**:
  Video panduan porsi gizi seimbang "Isi Piringku" dan pemenuhan Angka Kecukupan Gizi (AKG).
- **CCTV Live Stream Monitoring SPPG**:
  Stream feed/hls protokol untuk pemantauan real-time dapur penyedia.

## 2. Standar Format:
- Format: MP4 (H.264 / AAC) atau WebM
- Resolusi: 1080p / 720p Mobile-Optimized
- Bitrate Maksimal: 2.5 Mbps
- Batas Upload: Sesuai konfigurasi `.env` (`UPLOAD_MAX_MB=10`)
